# 『炭鉱掘りは夢を見る2』3Dビジュアル化・演出設計メモ

状態は構想段階。カードごとの演出や名称変更には未確定案を含む。

## 盤面と遊び方

カードで行動を指示し、その結果を3D空間で見せる。対戦する2人は隣り合った採掘拠点を持ち、斜めの坑口から地下へ入り、中央に向かって横坑を伸ばす。

| 場所 | 見せるもの |
| --- | --- |
| 地上 | 青と赤の開けた拠点。詰所、作業台、動力装置、資材置き場、麦畑、林、坑口。商人や継続効果の設備を置く場所も確保する。 |
| 地下 | 岩や土の層を見せる横長の断面。左右の坑道に支柱、レール、トロッコ、鉱石を置く。中央のゴール地点では岩盤に埋まった金ナゲットが断面から見える。 |
| 中央地下深部 | 両陣営に関わる異常現象を見せる空間。「深淵にて眠る者」の大空洞は、ここに以前から存在していたものとする。 |

- カメラは斜め上から。全景・地上・地下を切り替えられ、どの盤面にも両陣営を出す。ドラッグとズームで広い拠点や坑道を見回せる。
- ホームは模型を左寄りに置き、モード選択は盤面に重ねる。対戦の待合室ではアバターが自分の拠点へ歩いてくる。作業員は持ち場を歩き回り、アバターは夜に詰所へ入り朝に出てくる。
- 日中の空は残り時間と連動する。日没でターンが終わり、約1秒で次の朝へ。太陽は地平線の下を通って一周し、月は満月から一夜ごとに欠けていく。
- 3Dの既定は Ink Studio で焼いた Gaussian にピクセル処理をかけた表示。生の Gaussian とポリゴンも切り替えられる。カード、ゲージ、残り時間、ボタンはドット風の2D表示にする。
- 採掘値はゲーム上のスコア。岩が削れて坑道が伸びる量は、スコアの増分と物理的に一致させる必要はない。

## 最初に作る土台

1. 両拠点の詰所・畑・坑口に加え、クラフトの作業台、動力装置、木材・丸石・鉄・小麦の置き場を配置する。初期所持が0なら置き場は空にして、数量が増えると箱や資材の山を増やす。正確な数量はHUDで読む。
2. 作業台を開き、既存のクラフトレシピ、所持量と必要量、生成カードを確認する。作業台には選択中の完成品モデルを表示する。クラフトできる物は木・石・鉄のつるはし、斧、剣、鍬、シャベル、扉、盾、パンの計15種。
3. クラフトが成立したら資材置き場から箱を運び、作業台に完成品を出す。生成カードは既存処理で手札に入る。割引と鉄の完成品2枚も、既存の「上質な工具」「熟練の鍛冶師」の状態に従う。
4. 体力を拠点の「動力」として可視化する。通常は10灯で、上限が20の状態では2段になる。カード本文では既存の「体力」の表記を使う。

次の段階では、採掘、採取、補給をそれぞれ繰り返し使える演出にし、そのあとで継続設備やカード固有の出来事を足す。

開発者版では同じ盤面を使って両陣営の状態を設定し、カードを選んで効果を試せる。ピクセルサイズとディザリングもその場で調整する。個別演出は、共通の盤面更新から段階的に足していく。

## 共通の演出

- **採掘。** つるはしで切羽を掘る、発破やドリルで大きく開く、トロッコが自動で掘る、崩落で使える範囲が減る。切羽の岩は周囲の岩盤に馴染ませ、Gaussian が散って新しい空間が開く。採掘+20のような大きな変化は短い専用演出で表す。
- **作業員。** 詰所や坑道へ出入りする人数をゲームの値に連動させる。作業の手元を見せる装飾用の鉱夫とプレイヤーのアバターを別に管理し、正確な作業員数はHUDで確認する。
- **資源。** 木材、丸石、鉄、小麦を拠点へ運ぶ。大量取得は箱や山の段階で表す。伐採は背後の木を複数本使い分ける案と、切り株から成長させる案がある。
- **ドロー。** 「アイテム+N」はカード獲得を指す。補給箱や発見物から光や書類が出て、画面下の手札につながる流れを共用する。箱の出所でカードごとの違いを出す。頻繁に起きるので通常は短く、初回だけ長めに見せる案もある。
- **継続設備。** 効果が有効な間に動く。期限切れや解除を受けたら停止する、消灯する、撤去するなどして伝える。設備の数や段階は確定済みの効果に合わせる。

#### 深淵にて眠る者

- 使用時に大空洞を開く。卵の衝撃波で使用者の動力装置が拡張され、上限20と動力+10を見せる。
- ターン終了時に次の演出を出す。孵化したドラゴンの衝撃波が両坑道を駆け抜け、双方の採掘+20を表す。作業員が逃げる演出や、相手が先に逃げて自分が巻き込まれる案は、確定した勝敗に合わせる。
- 2回目以降は既存の空洞を使い、卵の揺れや発光などで進行を見せる。「夜までに掘りきる」は演出上の緊張感として使う。発動直後とターン終了のイベントは別に扱う。

## カード名の候補

名称の検討はカードIDや効果から切り離す。「深淵にて眠る者」「虹の雫」「神秘の加護」など、魔法や異常現象は世界観に残す方向。

| 現在の名称 | 候補 | 意図 |

| 大区画整備 | 倉庫整理／物資整理 | 整理による補給とつなぐ。 |
| 火気厳禁 | 危険物管理／禁火令 | 回収と相手への干渉を扱う。 |
| 快適な空の旅 | 空輸補給／追い風の補給 | 動力回復時に届く支援を表す。 |
| 利便性を求めて | 技術革新／研究成果 | 使用回数による装置の完成に結びつける。 |
| 生命量産機 | 自動人員供給装置 | 現実寄りの設備にする場合。 |
| 色彩の奏I〜VII | 虹の恩恵I〜VII | 虹の雫との関係を伝える。 |

## 実装時に決めること

- 採掘減少時は、掘った坑道が残って使用可能区画が減る案を第一候補とする。埋没や進行マーカーの後退も比較する。
- 崩落、同時採掘、深淵などを同じ盤面で見せ、操作や残り時間の読みやすさを保つ。連続するドローはまとめるか短縮する。
- 資産運用のインゴットは三角形に積む案。継続効果の重複と資産トークン数は別に参照する。有効数に応じた設備表示や、天への祈りでの一括解除も扱う。
- 演出は、成立したカード使用・クラフト、適用された増減、ターン開始／終了、勝敗を入力にする。カード効果、支払い、ターン処理、勝利条件はゲーム側の判断に従う。試作の固定デッキで扱う効果の範囲は [3D版のREADME](../README.md) を参照。
