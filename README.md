# 炭鉱掘りは夢を見る 3D

青と赤の拠点、斜めに入る坑口、左右から中央へ伸びる横坑を一つの模型にした試作です。地形の外寸は約59 × 23 × 13ワールド単位です。横坑の下に深淵用の空洞があります。

## 起動

Windows では用途に合わせて起動ファイルをダブルクリックします。Node.js 20 以上が必要です。

| 起動ファイル | 開く画面 |
| --- | --- |
| `Start 3D.cmd` | [通常版](http://127.0.0.1:4173/)。ホーム、対戦、盤面プレビュー。 |
| `Start 3D Developer.cmd` | [開発者版](http://127.0.0.1:4174/)。両陣営を操作できるローカルの試験盤面。 |

ターミナルからは初回に `npm ci` を実行します。通常版は `npm run build` のあと `npm start`、開発者版は `npm run developer` で起動します。

- [ホーム](http://127.0.0.1:4173/)で「盤面プレビュー」を押すと、途中盤面ですぐに試せます。
- 対戦するには「インターネット対戦」で部屋を作り、もう一方のブラウザーで同じサーバーを開いて部屋番号を入力します。部屋主が「対戦を始める」を押すと両方に盤面が出ます。
- 同じ LAN の端末から接続する場合は、サーバーの起動前に PowerShell で `$env:HOST = '0.0.0.0'` を設定します。参加側はホストPCのLAN内アドレスとポートを使います。ポートは `PORT` で設定できます。インターネット越しに遊ぶには、Socket.IO に対応した公開サーバーに配置します。

## 開発者版

- 「開発ツール」でカード名やIDを検索し、手札に追加するかその場で使います。特殊カードと「色彩の奏」も選べます。「資産」は手札に置くトークンで、「ターンエンド」は手番を終える操作です。
- 青・赤を選び、体力と上限、作業員、採掘、資材、資産、使用済みカード数を入力して「反映する」を押します。ターン数と残り秒も調整できます。「手番にする」で選んだ陣営から試せます。
- 初期状態では時計を止め、コストと使用制限を省略します。チェックを外すとルールに沿った支払いや時間制限を試せます。
- ピクセルサイズは1〜8 px、ディザリングは0〜15%をドラッグで切り替えます。操作すると盤面がドット表示になり、その場で変化を確認できます。
- 開発者版はローカル接続専用で、各タブが独立した試験盤面です。通常版の対戦ルームは通常版の起動先から利用します。

## 盤面で試せること

- 「全景」「地上」「地下」で見る範囲を変えられます。ドラッグで移動し、ホイールか ＋／− で拡大縮小します。Shift を押しながらドラッグすると回転できます。
- 「手札」か H キーでカードを出し入れできます。プレビューの「掘り進めI」で青の岩盤の Gaussian が散って1区画開き、「爆破工作」で赤の坑道が最大5区画崩れます。中央のゴール地点では、断面の岩盤に金ナゲットが見えます。
- HUD の体力は「動力」とし、両拠点の動力装置の点灯数に反映します。資材置き場の木材・丸石・鉄・小麦は所持量に応じて積み上がります。
- 作業台か「クラフト」を開くと、レシピと必要資材を確認できます。選んだ工具、扉、盾、パンなどの完成品が作業台に出ます。製作後は所持量と手札が更新されます。
- 部屋に入ったアバターは、各陣営の外側から拠点まで歩きます。作業員は自分の持ち場を歩き回ります。日没にアバターが詰所へ戻り、次の朝に外へ出ます。
- 太陽は地平線の下を通って一周します。休息を約1秒で早送りし、その間に月が昇ります。最初の夜は満月で、ターン交代による一夜を一日として、16日で月相が一周します。「日没を見る」で試せます。

## ルールの範囲

既存版の `GAME_RULES.md` と `MDD2_FULL_RULES_JP.md`、ローカル対戦のターン処理を参照しています。採掘15が勝利条件です。体力はカードの使用コストとして残し、0でも対戦は続きます。先攻の初期体力は2、後攻は3で、各プレイヤーの2回目以降のターン開始時に3回復します。通常の制限時間は120秒です。

通常版では、両陣営が同じ重複なし12枚の固定デッキを使います。初回に3枚、以降に1枚を引く処理と各ターンの支給品は、既存ローカル版の挙動に合わせました。固定デッキ、支給品、クラフトで入手するカードがプレイ可能です。開発者版は既存ローカル版のヘッドレス処理を使い、カード一覧から固定デッキ外の効果も試せます。

## 模型とUI

地形・松・岩・採掘区画は Gaussian を既定にします。Ink Studio の `S.bake()` と `B.finish()` で位置・密度・色・3D共分散を採取します。WebGL 2 で共分散を画面上の楕円に射影し、遠い順に画素ごとの Gaussian を合成します。Ink Studio の PixelLook を使い、固定のピクセル格子、輪郭の被覆、色パレット、ディザで仕上げます。家、作業員、トロッコなどの既存モデルは同じ深度バッファに描画します。 [Ink Studio](https://github.com/siliconjungle/shapeshift-labs-ink-studio/tree/d9a9147a54d964416cab27ace9de89636ef89d17) ／ [Silicon Jungle の公開プレビュー](https://fablelist.000ooo.ooo/w/pixel-art-gaussian-splats/)

ヘッダーで「ドット」「生Gaussian」「ポリゴン」を切り替えます。生Gaussianはピクセル格子、色パレット、ディザの処理を外した表示です。「描画比較」では視点を固定して3方式を計測できます。FPS、CPUの描画処理時間、対応環境でのGPU時間、描画呼び出し、描画要素数、メモリ、モデルファイルのサイズが表示されます。メモリ欄の対象は描画バッファと描画領域です。 [GPU時間の計測仕様](https://registry.khronos.org/webgl/extensions/EXT_disjoint_timer_query_webgl2/)

`npm run models` で両方式のモデルを再生成します。Gaussian は `public/models/coalfield.ink.gz`、ポリゴンは `public/models/coalfield.glb` に出力します。地形は `scripts/geology.cjs`、設備とアイテムは `scripts/camp-models.cjs` で定義します。 [gltfpack](https://meshoptimizer.org/gltf/)

盤面を広く使えるよう操作を端に寄せ、シルエットと陣営色で状況を読めるようにしました。ピクセル文字には DotGothic16 を使い、アイコンと空のピクセル画はこの試作用に描いています。 [Into the Breach の開発講演](https://media.gdcvault.com/gdc2019/presentations/Into%20the%20Breach%20Postmortem%20Final.pdf) ／ [Godot のピクセルフォント資料](https://docs.godotengine.org/en/stable/tutorials/ui/gui_using_fonts.html) ／ [DotGothic16](https://github.com/fontworks-fonts/DotGothic16/blob/master/README-JP.md)

拠点の構成や未確定のカード演出案は [3Dビジュアル化・演出設計メモ](docs/GAME_CONCEPT.md) を参照してください。
